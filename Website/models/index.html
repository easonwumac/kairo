Kairo Model Catalog

This static catalog is a reference seed for the planned easonwumac/kairo-models repository. Kairo fetches metadata from models.json. The current seed lists 13 downloadable GGUF models at 2B parameters or below, then downloads model files only after explicit user approval.

This site publishes metadata only. It does not host model weights, tokenizer blobs, API keys, access tokens, or license-gated artifacts.

Kairo Model Catalog

This static catalog is a reference seed for the planned easonwumac/kairo-models repository. Kairo fetches metadata from models.json. The current seed is a small Apache-2.0 starter list: Gemma 4 E2B IT QAT Q4_0, Qwen2.5 text fallbacks, Qwen2.5-VL 3B, and Gemma 4 E4B IT QAT Q4_0 with projector metadata. Kairo downloads model files only after explicit user approval. It can also publish benchmark profiles such as the Qwen2.5 0.5B GGUF/MLX Apple Silicon reference data.

This site publishes metadata only. It does not host model weights, tokenizer blobs, API keys, access tokens, or license-gated artifacts.

MLX benchmark entries are validation references for development machines unless a future iPhone runtime explicitly supports them; they are not proof of iPhone latency, memory, thermal behavior, or App Store packaging.
